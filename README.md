# 🎮 Game Design Studio – Multi-Agent AI System

Game Design Studio is an AI-powered multi-agent application that simulates the game design process. Different AI agents work together to analyze a game problem, research ideas, build a solution, and validate the final game concept.

## 🚀 Features

- AI-based game problem analysis
- Automated research and idea generation
- Game solution building
- AI-based validation
- Multi-agent workflow
- Interactive Streamlit interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Groq API
- AI / LLM Agents
- Requests
- Python-dotenv

## ⚙️ Setup & Run Locally

1. Clone the repository
```bash
   git clone https://github.com/Pravallika2919/game-design-studio.git
   cd game-design-studio
```
2. Install dependencies
```bash
   pip install -r requirements.txt
```
3. Add your Groq API key
   Create a `.env` file in the project root:
4. Run the app
```bash
   streamlit run app.py
```
