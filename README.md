# 🎮 Game Design Studio – Multi-Agent AI System

Game Design Studio is an AI-powered multi-agent application that simulates the game design process. Different AI agents work together to analyze a game problem, research ideas, build a solution, and validate the final game concept.

## 🚀 Features

- AI-based game problem analysis
- Automated research and idea generation
- Game solution building
- AI-based validation
- Multi-agent workflow
- Interactive Streamlit interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Groq API
- AI / LLM Agents
- Requests
- Python-dotenv
